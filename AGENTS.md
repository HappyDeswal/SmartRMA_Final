# Publishing workflow

This is the consolidated SmartRMA project. Publish completed validated source updates to `HappyDeswal/SmartRMA_Final`. The separate rebuilt project has been retired. Do not publish to SmartRMA_Publish for future work in this folder.

Preserve remote commits and never force-push. Keep runtime data, credentials, legacy histories, private backups/reports, datasets and learned weights excluded by .gitignore.
